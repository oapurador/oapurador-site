# oApurador — site institucional

Arquivos para publicação no GitHub Pages.

## Estrutura
- `index.html`: página principal.
- `assets/logo-oapurador.png`: marca utilizada no cabeçalho.

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie `index.html` e a pasta `assets` para a raiz do repositório GitHub.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch principal (por exemplo, `main`) e a pasta `/ (root)`.
6. Salve e aguarde a publicação.
